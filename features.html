기획서의 핵심 기능 5가지를 "어느 화면에서, 무엇을 하면, 무슨 일이 일어나는지"까지 구체적으로 풀어쓴 문서입니다.

Feature Definition

노똘똘의 견생 일지 — 기능정의서

기획서의 핵심 기능을 구체적으로 풀어쓴 문서 🐾

01. 사용자 시나리오

시나리오 1 — 방문한 사람이 똘똘이 소개 화면에서 사진 속 눈, 등, 발 같은 부위에 마우스를 가까이 대 보며 똘똘이의 세부 정보를 하나씩 알아간다.
시나리오 2 — 가족이나 친구가 사진첩에서 "2012년", "2013년" 같은 연도를 눌러 그해의 사진을 하나씩 구경한다.
시나리오 3 — 닥스훈트를 좋아하는 사람이 살아온 날들 화면에서 똘똘이가 태어난 지 며칠, 몇 시간이 됐는지 확인한다.
시나리오 4 — 방문한 사람이 한마디 남기기 화면에서 이름과 응원 메시지를 적어 남기고, 다른 사람이 남긴 메시지도 함께 읽는다.

02. 기능별 상세

신체 프로필 카드
목적 — 똘똘이가 어떤 아이인지 기본 정보는 한눈에, 자세한 정보는 사진을 살펴보며 알려주기 위해
어느 화면
똘똘이 소개
무엇을 하면
똘똘이 소개 화면에 들어오면, 그리고 사진 속 몸 부위(눈, 등, 다리, 발 등)에 마우스를 가까이 대면
무슨 일이
① 들어오면: 사진 양옆에 기본 정보 6가지(이름, 생일, 성별, 견종, 털색, 몸무게)가 3개씩 나뉘어 보인다
② 몸 부위에 마우스를 가까이 대면: 그 부위의 세부 정보만 말풍선으로 나타난다 (눈 → 눈 색, 등 → 등길이, 다리 → 높이, 발 → 발 크기). 마우스를 치우면 사라진다
화면 구성
화면 한가운데에 똘똘이 전체 모습(누끼 사진)이 크게 놓이고, 그 양옆으로 기본 정보 6칸이 갈래를 나눠 놓인다 (왼쪽 3칸, 오른쪽 3칸). 칸마다 정보 하나씩만 적고, 사진과 가는 선으로 이어진다 (핀터레스트 입양 사이트의 가운데 사진 구성 참고)
예시 그림
(사진 속 점에 마우스를 가까이 대 보세요)
이름노똘똘
생일2012.05.26만 14세
성별○○
🐕 눈 색다크 브라운 등길이○○cm 높이○○cm 발 크기○○cm
똘똘이 전체 사진
견종닥스훈트
털색초코탄
몸무게○○kg
※ 배치와 움직임을 보여주는 예시입니다. 실제 사이트에서는 가운데에 똘똘이 사진(배경을 오려낸 것)이 들어가고, 점은 눈, 등, 다리, 발처럼 실제 몸 부위 위에 놓입니다.
표시 항목
기본 정보 (6갈래, 항상 보임)
이름 · 생일(만 나이) · 성별 · 견종 · 털색 · 몸무게
세부 정보 (해당 부위에 마우스를 가까이 대면 보임)
눈 → 눈 색 / 등 → 등길이 / 다리 → 높이(어깨높이) / 발 → 발 크기 / 가슴 → 가슴둘레 / 귀 → 귀 모양 / 꼬리 → 꼬리 길이 등 (적고 싶은 만큼 추가)
움직임·효과
화면에 들어오면 사진이 먼저 나타나고 정보 칸이 사방에서 차례로 날아든다. 사진 위의 작은 점(●)이 "여기를 보세요"라고 깜빡이고, 마우스를 가까이 대면 그 점 위로 말풍선이 통통 튀며 나타난다
모바일에서는
마우스를 댈 수 없으므로 사진 속 점을 누르면 그 부위의 말풍선이 나타나고, 다시 누르거나 다른 곳을 누르면 사라진다. 사진이 위에 오고 기본 정보 6칸은 아래에 2칸씩 쌓인다
예외 상황
① 값이 비어 있는 항목은 "비밀이에요 🐾"로 표시한다
② 세부 정보가 너무 많으면 사진 옆에 다 띄우지 않고 "더 보기" 버튼으로 목록을 펼친다
③ 대표 사진이 없으면 기본 발바닥 일러스트로 대체한다
의존관계
없음 — 정해진 글자를 그대로 보여준다
호불호 카드
목적 — 똘똘이의 성격과 취향을 귀엽게 알려주기 위해
어느 화면
똘똘이 소개
무엇을 하면
카드에 마우스를 올리거나 (모바일에서는) 카드를 누르면
무슨 일이
"좋아해요" 카드는 핑크색, "싫어해요" 카드는 초콜릿색으로 구분되어 보이고, 카드가 뒤집히며 이유나 한 줄 설명이 나타난다
화면 구성
"좋아해요"와 "싫어해요" 두 묶음. 각 카드에는 아이콘(또는 일러스트)과 짧은 제목이 있다
움직임·효과
카드에 마우스를 올리면 색과 글자, 이모티콘이 바뀌며 카드 뒷면에 설명이 보인다 (로보토리 참고)
표시 내용 예시
좋아요: 간식, 산책, 가족 무릎 / 싫어요: 목욕, 천둥소리, 혼자 있기 (실제 내용으로 바꿔 쓴다)
모바일에서는
마우스를 올릴 수 없으므로 카드를 한 번 누르면 뒤집히고, 다시 누르면 돌아온다
예외 상황
① 카드가 많으면 6개까지만 먼저 보이고 "더 보기" 버튼으로 펼친다
② 설명이 없는 카드는 뒤집히지 않고 제목만 보여준다
의존관계
없음
연도별 사진 갤러리
목적 — 열네 해 동안의 똘똘이 모습을 연도별로 한눈에 보여주기 위해
어느 화면
사진첩
무엇을 하면
연도 탭(2012, 2013 …)을 누르면, 그리고 사진을 눌러서
무슨 일이
그 연도의 사진들이 격자 모양으로 바뀌어 보이고, 사진을 누르면 크게 확대되어 보인다. 확대된 화면에서는 좌우로 넘기거나 닫기 버튼으로 돌아갈 수 있다
화면 구성
맨 위에 연도 탭(2012~지금), 그 아래에 아치형 모서리의 사진 격자. 사진 위에는 연도와 한 줄 설명이 작게 붙는다
움직임·효과
① 사진에 마우스를 올리면 부드럽게 커진다
② 사진들이 스크롤을 내리면 그때 아래에서 떠오르며 나타난다
③ 확대 화면에서는 사진이 옆으로 밀리며 넘어간다 (Zoom 참고)
모바일에서는
격자가 2열로 줄고, 확대 화면에서는 손가락으로 좌우로 밀어 넘긴다
필요한 사진
연도별 최소 1장 이상, 가로·세로 섞여 있어도 되며 한 장당 2MB 이하로 줄여서 쓴다
예외 상황
① 그 연도에 사진이 없으면 "이 해의 사진은 아직 없어요 🐾" 문구를 보여준다
② 사진 파일을 불러오지 못하면 회색 배경에 발바닥 아이콘으로 대체한다
의존관계
없음 — 사진 파일(img 폴더)만 있으면 된다
살아온 날 계산기
목적 — 열네 살이 넘은 똘똘이가 얼마나 오래 함께했는지 숫자로 실감하게 하기 위해
어느 화면
살아온 날들
무엇을 하면
화면에 들어오면 (아무것도 누르지 않아도)
무슨 일이
생일(2012.05.26)부터 지금까지의 연, 달, 일, 시간이 0부터 올라가며 보인다. 시간(시·분·초)은 화면을 보는 동안 계속 바뀐다
화면 구성
제일 위에 "태어난 지 ○○일째" 큰 숫자, 그 아래에 연·달·일·시간 4칸. 아래에는 지나온 해를 따라 걷는 똘똘이 일러스트가 있다
움직임·효과
화면이 고정된 채 스크롤하는 만큼 숫자가 0에서 오늘 숫자까지 올라가고, 🐕가 걸으며 발자국이 찍힌다
계산 기준
연·달은 달력 기준(생일 달·일을 지났는지)으로 세고, 일·시간은 생일 0시부터 지금까지 지난 총합으로 보여준다
표시 내용 예시
14년 4개월 / 5,000일 넘게 / 12만 시간 넘게처럼 천 단위 쉼표를 넣어 읽기 쉽게 보여준다
예외 상황
① 윤년과 달마다 날짜 수가 다른 것을 반영해서 계산한다
② 자정이 넘어가면 일 수가 자동으로 하나 늘어난다
의존관계
없음 — 생일만 정해져 있으면 된다
한마디 남기기
목적 — 가족과 친구가 똘똘이에게 하고 싶은 말을 남길 수 있게 하기 위해 (로그인 없이 누구나 쓸 수 있다)
어느 화면
한마디 남기기
무엇을 하면
이름과 메시지를 입력하고 "남기기" 버튼을 누르면
입력값 제약
이름 최대 10자, 메시지 최대 100자
무슨 일이
"똘똘이에게 전달됐어요 🐾" 메시지가 뜨고, 입력창이 비워지며, 방금 쓴 메시지가 목록 맨 위에 새 카드로 추가된다
화면 구성
위에 이름과 메시지 입력창과 "남기기" 버튼, 그 아래에 다른 사람이 남긴 메시지 카드가 최신순으로 쌓인다. 카드마다 이름, 내용, 쓴 날짜가 보인다
움직임·효과
입력창 위에서 마우스 커서가 닥스훈트 얼굴로 바뀌고, "남기기" 버튼 위에서는 활짝 웃는 표정이 된다 (eggiscoming 참고). 새 메시지는 위에서 부드럽게 떨어지며 추가된다
표시 문구
남기기 전: "똘똘이에게 하고 싶은 말을 적어 주세요" / 성공: "똘똘이에게 전달됐어요 🐾" / 실패: "지금은 저장하지 못했어요. 잠시 후 다시 시도해 주세요"
저장 실패 시
네트워크가 끊기거나 저장에 실패하면 입력한 내용을 지우지 않고 그대로 두어 다시 눌러 볼 수 있게 한다
예외 상황
① 이름이나 메시지를 안 채우면 저장되지 않고 어떤 항목이 비었는지 안내 문구가 뜬다
② 글자 수를 넘기면 "100자까지 쓸 수 있어요" 안내 문구가 뜬다
③ 같은 내용을 연달아 남기려 하면 "방금 남긴 메시지와 같아요" 안내 문구가 뜬다
④ 아직 남겨진 메시지가 없으면 "첫 번째 한마디를 남겨 주세요" 문구를 보여준다
의존관계
메시지를 저장하고 불러올 데이터베이스(Supabase)가 먼저 준비되어 있어야 한다

04. 모든 화면의 공통 동작

로딩 화면 — 사이트에 처음 들어오면 발바닥이 통통 튀고 진행 막대가 차오르는 화면이 먼저 나온다. 모든 화면 준비가 끝나면 부드럽게 사라지고, 같은 방문 중에는 다시 보이지 않는다.
메뉴 — 화면 위쪽에 항상 보이고, 현재 화면의 메뉴는 핑크색으로 표시한다. 모바일에서는 햄버거 버튼으로 접어 둔다.
스크롤 나타나기 — 처음부터 다 보이는 것이 아니라, 스크롤을 내리면 그 구간의 사진과 글이 아래에서 떠오르며 나타난다.
마우스 커서 — PC에서는 닥스훈트 얼굴 커서가 따라다니고, 클릭할 수 있는 곳(버튼, 카드)에서는 표정이 바뀐다. 터치 기기에서는 기본 터치 동작을 쓴다.
화면 크기 — 휴대폰, 태블릿, PC에서 모두 글자가 잘리지 않고 한글 단어가 중간에서 끊기지 않게 보인다.
